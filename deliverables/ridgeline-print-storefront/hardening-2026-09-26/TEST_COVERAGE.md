# Local evidence: functional coverage and limits

The current deterministic backend suite passed **203 of 203 assertions** on the dedicated `ridgeline-api-hardening` container at port 3311. It uses HTTP requests, independent arithmetic from the supplied seed and read-only SQLite row counts. It also performs one actual container/process restart over the same database. The independent rubric arithmetic script passed **19 of 19 scenarios**.

These are local engineering checks. They are not a browser-judge verdict, a paid Oracle score, or evidence of a target-model score. No backend suite was repeated for this mapping.

## Source-review follow-up for browser retry recovery

The read-only review of `solution/app/public/assets/app.js` found a browser-specific concern after the backend suite passed: a checkout may commit before its response is lost. Repricing the now-depleted basket after reload can disable the ordinary checkout buttons, preventing replay of the saved identity. Editing the address or cart after an ambiguous failure can also rotate the identity before the first attempt has been resolved. These concerns were sent to the root and UI agent for a targeted browser reproduction/fix; they are not backend-suite failures. The UI evidence and final source review must record their resolution before treating local end-to-end retry recovery as complete.
