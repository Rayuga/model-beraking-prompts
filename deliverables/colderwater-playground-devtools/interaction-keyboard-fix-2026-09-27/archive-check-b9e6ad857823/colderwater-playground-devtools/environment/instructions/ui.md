# Working in the playground

I'd like the editor, preview and console visible as three useful panes. Let me drag the dividers to resize them and keep those sizes after a reload. On a narrow screen they can rearrange or stack, as long as I can still reach each pane and its controls.

The editor needs a monospaced face, line numbers and syntax colouring for JavaScript, HTML and CSS. When the cursor is beside either bracket of a complete pair, show the matching pair. For a selection of several lines, Tab should indent all of them consistently and Shift+Tab should take off one matching level without deleting code. Choose the indentation width yourself.

Include title and filename fields, Run, Stop, Auto-run, Clear console, the examples and the saved-library actions. The wording and placement of controls are up to you. Please show the working keyboard shortcuts for Run, Save and Clear console somewhere people can find them.

Light and dark themes should cover the workspace, including the editor syntax, console and preview surround. Either theme can be the starting one. Keep text legible, controls labelled and keyboard focus visible; I should be able to navigate without a pointer. An authored preview document can keep the colours its own code specifies.
