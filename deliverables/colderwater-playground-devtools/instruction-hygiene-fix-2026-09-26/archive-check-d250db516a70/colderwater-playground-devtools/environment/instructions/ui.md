# Working in the playground

Keep the editor, live preview and console visible as three useful panes. Let users resize them by dragging dividers and remember their sizes across a page reload. On narrow screens they can rearrange or stack, but each pane and its controls must remain usable.

The editor uses a monospaced face, a line-number gutter, syntax colouring appropriate to JavaScript, HTML and CSS, and a visible matching-bracket highlight when the cursor is beside either bracket of a complete pair. Tab indents every selected line consistently; Shift+Tab removes one matching level without deleting the selected code. The indentation width is your choice.

Include filename and title fields, Run, Stop, an Auto-run switch, Clear console, a way to choose examples, and the saved-library actions. A particular layout or control label is not required. Document working keyboard shortcuts for Run, Save and Clear console.

Offer light and dark themes for the whole interface, including editor syntax, console and preview surround. Either can be the initial theme. Keep both legible, with visible keyboard focus, labelled controls and navigation that works without a pointer.
