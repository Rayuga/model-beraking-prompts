# Scope and product choices

This is a local development playground, not an authenticated collaboration service or a general-purpose remote execution host. There is one shared saved library and no private account data. Several browser tabs may edit the same saved record, which is why saves and deletes need revision conflict protection.

Choose the layout, control wording, indentation width, API routes and payload field names. Keep the observable behaviors in the other notes consistent across the interface and saved records. Unsupported input should explain what happened and leave the surrounding app usable.

Build your own examples and interface. No participant starter implementation is supplied. Ordinary local source/build dependencies are permitted during development; the finished app must contain what it needs to run offline.
