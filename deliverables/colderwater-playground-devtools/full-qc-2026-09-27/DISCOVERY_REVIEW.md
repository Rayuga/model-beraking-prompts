## Confidentiality classifier limits

The three fixed negative paths are bounded leak probes, not mandatory product endpoints. HTTP 200, JavaScript MIME or JSON alone cannot establish exposure. An SPA fallback, denial, harmless public frontend manifest or browser JavaScript named `server.js` is allowed. SQLite's exact first-16-byte `SQLite format 3` magic provides a concrete positive signature. Package classification requires server-only dependency and server-start signals together, not generic `name`/`version`/`scripts`. Raw server source needs multiple unambiguous server import/initialization signals and an HTML exclusion. Read at most the specified bounded prefix in browser automation, return only classification/truncation metadata, and never dump source or secret values. A completed bounded observation with no positive private signature passes this representative probe, including larger or unrecognized payloads; report the limited prefix scope rather than claiming exhaustive secrecy. A transport/setup failure provides no such observation and cannot establish a pass. The earlier working-draft demand to prove every body public is withdrawn.
