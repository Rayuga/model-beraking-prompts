Residual interpretation risk: platform review may define “independent” more narrowly than useful feature/policy. Remaining representative groupings include JS/HTML filename dispatch, case acceptance across supported forms, CSS script/handler exclusion, warning/cancel variants across replacement routes, ordered console level delivery, and UI/server enforcement of one title-uniqueness invariant. Those groupings are named rather than hidden. Splitting each mechanism/variant would increase row count again without eliminating the need for the same bounded browser observations. The current proposal follows the parent-reviewed compact feature level, not the previously overbroad all-flow rule.
