# The playground

Build a useful playground with TypeScript, React and Vite, and SQLite for the saved library. It is a public local application: no accounts, sign-in, remote service or supplied starter implementation.

The workspace has a code editor, live preview and console. A new installation with no saved snippets opens a working example and runs it automatically, so there is real code, rendered output and console feedback without a setup step. Include useful examples of your own, while allowing a new draft written entirely from scratch.

The filename determines whether a run is JavaScript, HTML or CSS. A language indicator or additional control is fine, but changing the filename alone must select the correct behavior. The supported file extensions are .js, .html and .css, regardless of letter case.

People can name, save and load snippets, rename them, make independent duplicates, delete with confirmation, and import or export a single source file. These workflows and their conflict rules are in behaviour.md. The library is durable; examples are part of the shipped app, not seeded user records.
