# The playground

The main workspace is an editor, a live preview and a console. When I open the app, I want useful code already there and its preview and console output produced automatically. It can start with one of your examples or a saved snippet; the library doesn't have to be empty. Please include some useful examples and let me start a new draft from scratch too.

The filename tells the app what I'm running. Changing it to .js, .html or .css should be enough, regardless of capitals in the extension. A language indicator or another control is fine, but I shouldn't have to keep a separate selector in sync.

The saved library is shared by the local app. I can save and load snippets, rename them, make independent copies and delete ones I no longer need. Import and export each deal with a single source file. There are no accounts or private libraries.

The examples come with the app; they're separate from saved user records. We haven't supplied an implementation or starter snippets. The library and file-handling details are in /instructions/behaviour.md.
