# PatchPad Editor

I want to build PatchPad, a browser-based editor for long incident reports.
It should make editing comfortable, keep a reliable revision history, and
protect people's work when two tabs try to save changes.

Start with the report in `/assets/incident_seed.json`.

I've put the detailed brief in `/instructions/`: `overview.md`, `editing.md`,
`persistence.md`, `conflict-safety.md`, and `interface.md`. Please read those
before building. The layout and implementation are up to you within that brief.
