# Common Ground Ballot

Can you put together Common Ground, a private ballot workspace for our
membership group? It needs to feel like a real product rather than a static
dashboard. Records should stick, and the people using it do not all have the
same access.

The rest of the brief is in `/instructions/`: `overview.md`, `ballots.md`,
`privacy.md`, `runtime.md`, and `interface.md`. The starting records are in
`/assets/artifacts/common_ground_seed.json`; treat that file as authoritative.
A small runnable base is available in `/assets/starter/`; copy it into `/app`
and build from there instead of assembling the browser shell from scratch.

Routes and element names are up to you. Work through the supplied ballots as
each demo user, make a new decision from draft through publication, and check
that accepted changes survive a fresh sign-in.

This is a local demo. Registration, email delivery, public result links,
imports, exports, and real-world election certification are out of scope.
