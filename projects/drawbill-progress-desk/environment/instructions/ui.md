# Interface

Routes, labels, and element ids are yours to choose. Everything has to be
findable by intent — assume nobody tells the person using it where to click.

Finance lives in this thing in a browser all day. There is no browser on the
box you are building on, so nothing will tell you if the first script throws:
a page that comes up empty because of one undefined function is not a desk,
however good the server behind it is. Keep the front end small enough that you
can be sure it runs.
