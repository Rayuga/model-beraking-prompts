# After pay, staff actions, and status

After a card has been charged, that period should no longer read like an
open pencil. Avery's own papers, the paid copies the notice desk kept, the
texts, the email copies, the punches on a member card, the diary holds, and
waivers. Harper has the audit trail. Staff-labeled actions the demo uses
constantly: file Harborview App 2, certify Harborview App 2, release
Harborview to the rail, and the matching Downtown / Riverwalk actions. A
visible control that changes which seeded user is active, with no login.

When the app turns a payment or a certification down, the person in front
of it has to be able to see that it was turned down, and get some idea
why, without leaving the screen they were on.

Finance also wants a plain status surface they can hit without opening the
product — one that says the app is up and names the engine the books are
kept in. Reach it by intent; the path is yours.
