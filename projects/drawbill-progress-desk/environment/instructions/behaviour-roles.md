# Who can do what

Priya's company is on hold. She can look at Westfork's pencil. She cannot
leave pencil and she cannot pay. Chris has no jobs, no notices, no
waivers, no punches. A name typed onto a request is not a second switcher.
A request with no identity header is still Avery. A value that matches
nobody is turned away; it does not become Avery.

Jonah can keep the SOV and help file a pencil. He does not pay. Diego
does not file owner papers. Helen does not certify. Ruth does not file.
Marcus does not read foundations. Lena does not read steel. Harper reads
and does not write. Harborview's policies through the end of 2030 are
already on file; do not make Avery hunt for them.
