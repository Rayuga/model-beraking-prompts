# Fee, extras, and bond

Fee is not one percentage. Original this-period work (including converted
iron, excluding general conditions, excluding the new pile) takes eight.
Executed extras take six. Someone ran the mill extra at eight because it
was sitting inside 03-200, and Victor caught it because it did not match
the index ticket. The mill extra is forty thousand and the index desk
already knows; typing forty thousand that does not match the index is not
an extra. CO-02 is still draft, and a draft is not an extra: only executed
extras take six, and only an executed extra lifts a line's ceiling.

Bond is once, on the original contract, on the first posted paper.
Harborview already posted March's bond. A second rider on April is not a
fee.
