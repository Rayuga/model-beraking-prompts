# Trust

## Who is asking

The switcher in the interface decides which seeded person is using the app. It
is part of the demo. A name typed into a billing request is not a
second switcher — the person on the switcher is the one on the paper.
A value that matches nobody in the plant is turned away; it does not
become Avery or anyone else. A role name typed onto the request — in
the header, the body, or the query — is not a promotion.
