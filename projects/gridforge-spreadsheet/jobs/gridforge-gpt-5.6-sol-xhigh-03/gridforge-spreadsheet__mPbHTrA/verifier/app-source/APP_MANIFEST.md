# GridForge

```bash start
cd /app && npm start
```

SQLite database: `/app/gridforge.sqlite`

Main API routes: `GET /api/users`, `GET /api/workbooks`, `GET /api/workbooks/:id`, `POST /api/workbooks/:id/save`, `GET /api/workbooks/:id/revisions`, `GET /api/workbooks/:id/revisions/:revision`, `GET /api/workbooks/:id/history/:sheet/:address`, `GET /api/events`, `POST /api/presence`.
