# Choices left to you

This is one local shared workspace, without sign-in or private accounts. You may choose the layout, labels, routes, database schema and error wording. A parser or formatter library is fine; the editing surface itself is the part I want you to write, as ui.md describes.

These notes describe how I'll use the app; the examples are there to explain, not to dictate selectors, CSS classes or how you build it. Please keep the app usable when a draft has broken code in it or a save gets refused.
