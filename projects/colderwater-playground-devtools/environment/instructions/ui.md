# Working in the playground

I'd like the editor, preview and console visible as three useful panes. On a narrow screen they can rearrange or stack, as long as I can still reach each pane and its controls.

The editor needs a monospaced face, line numbers and syntax colouring for JavaScript, HTML and CSS.

Include title and filename fields, Run, Stop, Auto-run, Clear console, the examples and the saved-library actions. The wording and placement of controls are up to you.

Light and dark themes should cover the workspace, including the editor syntax, console and preview surround. Either theme can be the starting one. Keep text legible, controls labelled and keyboard focus visible; I should be able to navigate without a pointer. An authored preview document can keep the colours its own code specifies.
