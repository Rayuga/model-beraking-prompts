# The playground

Show the code editor, preview and console together. New drafts start empty or with a small example. The saved library is shared by open tabs, without accounts, and stays current in each of them while I work. A snippet has a title, a .js or .html filename, exact source and a revision history. The filename chooses the execution mode.

I want the editor to be a useful tool in its own right. I often work on one very long line, so it needs to stay editable, and formatting, selection, multiple carets and undo should all work on the code that will actually run. Please keep the preview separate from where I edit.
