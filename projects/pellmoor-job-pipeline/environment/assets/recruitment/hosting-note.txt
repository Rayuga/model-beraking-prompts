how the box works - read before you start
-----------------------------------------

Cal asked me to write this down because the last two people both guessed and
both guessed differently. This is not a preference list, it is what will boot.

Where it goes
  /app. That exact path. The deploy script cds into it directly.

What to build it with
  TypeScript on the browser side, bundled with esbuild. The funnel is drawn with
  d3 - we already licence nothing and I am not adding a chart library for one
  chart. Express on the server, SQLite on disk.

  Node and the server packages are on the box already. Declare what you use in a
  package.json, but the running app installs nothing and fetches nothing.

How it starts
  npm run build && node backend/server.js

  In that order. It listens on 3000. It serves the browser side out of
  public/index.html and normally keeps its database at /app/pellmoor.db. The
  runner may provide DB_PATH when it needs another writable location; use that
  path when it is present.
