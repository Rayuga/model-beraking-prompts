# TorqueBay Enterprise

Build TorqueBay, the shop-floor desk for a multi-bay commercial garage.
Trucks are already in the bays and estimates are waiting on customers. It
has to be a real server with durable storage, not a static board.

The rest of the brief is in `/instructions/overview.md`,
`/instructions/behaviour.md`, `/instructions/security.md`,
`/instructions/ui.md`, `/instructions/integration.md`, and
`/instructions/policy.md`. Read all of them before you build. The starting
records are the three JSON files in `/assets/artifacts/` — copy those into
`/app` so the shop can boot from them.

A fresh browser should open as service advisor Nora Adler, with a way to
see the day as other staff or as a customer. Put the finished app in `/app`.
