# Mouse and keyboard controls

Provide seven visible column controls aligned with the board. Players must be
able to drop a piece with the mouse.

Keyboard focus belongs to an active column. Left and Right move between
adjacent columns, Home and End select the first and last columns, and Enter or
Space drops a piece. Boundary movement must stay within the seven columns, and
focus should remain on the selected column after an accepted move.

Hovering or focusing a playable column should preview the current player's
piece in that column.
