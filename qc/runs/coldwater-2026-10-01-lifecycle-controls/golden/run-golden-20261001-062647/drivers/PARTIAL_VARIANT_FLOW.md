# Partial variant driver: unexecuted preparation

`partial_variant_flow.cjs` exports `runVariant(driver, ledger, variant, fixtures)` using `workflow_core.cjs`'s driver and observation ledger. It never launches a browser or writes evidence by itself. Execution requires `fixtures.freeze_confirmed === true`. Canonical variant names match the three mutation exports; `import`, `titles`, and `css` are aliases. A disposable app with exactly the selected mutation must already be running when the parent later authorizes execution.

Fixtures can provide a safe `token`, override `import`, `titles`, or `css` values, and provide `criterion_map` keyed by full observation ID (`partial.import.server_filename_validation`, for example) or its final fact key. `FINAL_FACT_BINDINGS` supplies supporting owner IDs from frozen candidate `9bec05c2155f` (88 owners), including the separate saved-filename extension and path owners. Unmapped controls remain provisional. Multiple observations may support one owner; the module does not turn any one observation into a complete criterion verdict. The launcher must bind actual fixture/source hashes before execution; no current score or Oracle score is asserted.

Each row has `product_pass`, `expected_product_pass`, `probe_completed`, and `expectation_matched`. Ledger `observed pass` means only that the probe collected its observation. An intended mutant defect has `product_pass:false` plus `expected_defect_observed:true`; an unrelated failure cannot match the expected defect. Missing prerequisite evidence is separate from a demonstrated product result. Independent branches continue after an earlier failure.

- Import uses the actual file input with exact `.JS` bytes, a working preview control, a two-second off window and manual Run. It separately imports lowercase `.js`, saves that real draft, edits/saves/reloads it, checks unsupported UI import preserves all draft fields, and imports/saves/reloads uppercase `.JS`. Its server check independently creates/updates a valid record and replays the captured update shape with its current revision and `unsupported.txt`; import success is retained when server validation fails. A later branch rereads and restores supported filename state, captures a fresh valid update, then tests `nested/demo.js` with the actual current revision. It must still reject the path without mutation.
- Titles independently observe padded create, padded rename, a dedicated case-only title pair and recovery to an unused name. The mutation should preserve trimming and wrongly reject the case-only second record.
- CSS observes uppercase JS and HTML dispatch, a real pre-CSS handler, uppercase CSS styling, the prior `rgb(1, 2, 3)` background, script count, post-CSS handler behavior and a fresh JS document/global result separately. Its handler event poll is bounded to two seconds; it is not an additional five-second requirement wait.

The driver author has run no transformations, application build, browser, container or provider for this driver. `node --check partial_variant_flow.cjs` passed.
