# Disposable reference mutations: plan only

`variant_mutations.cjs` exports three pure text-to-text transformations and their exact baseline source hashes. It imports only Node's hashing module; it does not read/write files, build an app, start a process, contact a service, or run a browser. Each function takes one unmodified UTF-8 source string and returns one changed string. Apply variants separately to fresh disposable copies after the parent's grading freeze and runtime authorization. The helper rejects base drift, including line-ending changes, and requires each replacement anchor exactly once. It deliberately does not compose mutations or accept an already-mutated source.
