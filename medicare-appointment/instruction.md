# Task: MedCare Appointments — a healthcare booking portal

Build a small full-stack web app called **MedCare**. Patients book doctors
through Stripe Checkout; doctors run their own day and write up the visits they
finish.

## Read these first

The brief is already in this container under `/instructions/`, split across
`overview.md`, `behaviour.md`, `security.md`, `integration.md`, `ui.md`, and
`policy.md`. **Read all of them before you write anything.** They are one
document split by topic and none of it is optional.

`behaviour.md` is the clinic talking about its own business. It is not a
specification and it is not a checklist.

`/assets/CREDENTIALS.md` covers the Stripe test environment variables.
`/assets/artifacts/` holds the seed JSON for the doctors and patients.

Nothing in the product should need a route or an element id explained before it
can be used.
